# v1.1.0-M1+hc28 发版说明（版本串 v1.0.0-rc.51+hc28）

**日期**: 2026-11-15
**基线**: hc27（`2cb59e25`，上游 v1.0.0-rc.51）+ 严格依据 `.deploy/v1.1.0-大版本更新介绍.md`（315 项规划）从零自研
**范围**: M1 里程碑四个能力包，共 **31 项**（B01-B05/B75-B78/B139-B144、B06/B07/B08/B09/B14、B71/B72/B73/B82、B19/B20/B21/B22/B23/B26）

## 概述

hc28 是 v1.1.0 大版本的第一个里程碑（M1），按版本说明逐项自研实现，
**不使用任何 harness 现成实现**。全部改动围绕四条主线：

1. **安全基线**（15 项）：让面板的 Cookie/CSRF/CSP/SRI、渠道密钥落库、
   管理入口、审计日志达到生产级防护标准
2. **稳定与运维**（5 项）：版本可追溯、健康检查、指标暴露、日志写放大治理、
   订单状态实时推送
3. **计费可信**（4 项）：计费异常/系统任务/渠道健康的主动告警、上游 usage
   缺失时的兜底估算
4. **运营台**（7 项）：审计页、公开售卖页、邀请返利闭环、倍率变更影响预览、
   危险操作二次确认、对账月结单

## 前端性能优化（hc28 追加）

### 图标静态化（治理 react-icons 桶加载）

- 问题：`react-icon-by-name.tsx` 用 `import('react-icons/xx')` 动态加载 29 个完整
  图标包，最坏情况产物多出 **61MB 异步 JS（1729 个 chunk）**——管理员只要把支付
  方式图标配成 `SiAlipay`，每个访客的支付页就要下载 5.1MB
- 方案：构建期把 `si`（Simple Icons 品牌）+ `lu`（Lucide 线性）两个包预渲染成
  **4987 个静态 SVG**（`web/public/icons/`，约 15MB、单个 1~4KB），运行时用 CSS
  mask 引用、`currentColor` 跟随主题；任意图标名仍然可用，不支持的名称依旧不
  显示图标，扩展只需在 `ICON_PACKS` 加一行
- 落点：`web/scripts/generate-icon-assets.mjs`（新，幂等 stamp 缓存）、
  `web/scripts/generate-icon-assets.d.mts`、`web/src/components/react-icon-by-name.tsx`
  （重写）、`web/src/lib/icon-asset.ts`（新）、`web/rsbuild.config.ts`
  （prod 构建前自动生成）、`web/package.json`（`react-icons` 移到 devDependencies）

### i18n 语言包按需加载

- 问题：7 个语言包（en/zh/fr/ja/ru/vi/zh-TW，合计约 4.7MB JSON）在 `i18n/config.ts`
  里静态 import，全部打进主包
- 方案：自定义 i18next backend 插件 + 动态 import；`preloadLocales()` 在首帧渲染
  前只加载当前语言，切换语言时再拉对应 chunk（Map 缓存防重复 read）；
  `fallbackLng` 调整为 zhTW→[zhCN,en]、其余→[en]——en 是唯一全量键位语言，
  fr/ja/ru/vi 各缺的 64 键从「回退中文」变为「回退英文」，属行为改善
- 落点：`web/src/i18n/config.ts`（重写）、`web/src/main.tsx`（挂载等待 locale
  就绪）、`web/src/i18n/config.test.ts`（新）

### 现网（hc26 → hc28）等价重建命令

现网 `new-api` 容器由 `docker run` 直接启动（无 compose 元数据），
镜像仍是 `v1.0.0-rc.43-hc26`，bind 挂载 `data/`：

```powershell
# 先备份数据库（/data/new-api.db，含 WAL 文件）
docker cp new-api:/data/new-api.db "$PWD\backups\$(Get-Date -Format yyyyMMdd-HHmmss)-new-api.db"

docker rm -f new-api
docker run -d --name new-api --restart unless-stopped `
  -p 3000:3000 `
  -v "D:\workbuddy\2026-10-12-19-15-15\new-api-src\new-api-1.0.0-rc.43\data:/data" `
  -e TZ=Asia/Shanghai `
  delta-api/new-api:v1.0.0-rc.51-hc28
```

镜像已内置 `SQLITE_PATH=/data/new-api.db?_pragma=busy_timeout(30000)&_pragma=journal_mode(WAL)&_txlock=immediate`，
无需再传。健康检查走 `/api/status`，`start-period=40s`，约 1 分钟转为 `healthy`。

### 构建环境备注（hc28 首次镜像交付踩坑）

- 上游 `golang:1.27-alpine`、`alpine:3.21` 的 tag 已漂移到本地没有的新 digest，
  而 Docker Hub 的 blob CDN 在构建网络下直连 0B 停滞 → 用 pin 了本地
  `RepoDigests` 的 Dockerfile 副本（`D:\workbuddy\2026-10-12-19-15-15\Dockerfile.hc28`）
  加 `--pull=false` 完成全离线构建，历史层全部命中（前端 76s、Go 编译 4s）
- Docker Desktop 随启动它的 shell 退出而终止，改用 `explorer.exe` 作为父进程启动后，
  daemon 独立存活，任意 shell 的 docker 客户端均可复用
