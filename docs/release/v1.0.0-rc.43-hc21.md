# v1.0.0-rc.43-hc21 发版说明

## 主题:管理员「扩展设置」统一界面 + 修复设置失效项

## 功能变更

### 1. 新增管理员页面「扩展设置」(/enhanced-settings)
侧边栏「管理」组新增入口(ADMIN 及以上可见),把本二开系列新增的设置聚合到一个页面,保存即生效:
- **免费 / 付费分组隔离**:免费分组白名单(FreeQuotaAllowedGroups)——白名单内=免费分组,白名单外=付费分组(仅付费余额可消耗、免费级 key 不可路由);
- **号池设置**:用户自助贡献的每日额度、单次 Token 上限、开放自助贡献、自动绑定上游模型;
- **巡检设置**:单模型自动检查与自动下架(含到「渠道健康」页的指引链接)。

### 2. 修复:渠道健康页保存「单模型自动检查」报错
`monitor_setting.model_auto_check_enabled` 之前不在 request_policy 选项白名单里,
渠道健康页读得到但保存会报 `not a request policy option`。已加入白名单(model/request_policy.go),
该开关现在也可在「系统设置 → 请求策略 → 渠道健康」直接配置。

### 3. 号池设置卡说明更新
「自动绑定上游模型列表」的说明补充:该开关同时控制巡检前是否自动刷新号池渠道的上游全量模型(hc19 行为)。

## 升级步骤

```bash
docker load -i new-api-v1.0.0-rc.43-hc21.tar
docker compose -f deploy/docker-compose.prod.yml up -d
```

无数据库迁移;无新增配置项。旧设置入口(号池页设置卡)仍可用,两处读写同一配置。
