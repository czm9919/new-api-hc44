# v1.0.0-rc.43-hc20 发版说明

## 主题:免费与付费隔离(key 隔离 / 模型隔离 / 余额隔离)

hc17 把「免费额度能在哪些分组消耗」做了白名单,hc20 在此基础上把隔离补完整:

## 功能变更

### 1. key 隔离:免费级 key 与付费 key 分开发放
- **判定规则**:号池发放的 Token(`SourceChannelId > 0`)自动视为**免费级 key**,无需任何配置;充值/管理员普通生成的 Token 为付费 key。无新表字段,升级即生效。
- **路由硬限制**:免费级 key 只能路由到免费分组白名单(`FreeQuotaAllowedGroups`)内的分组:
  - 期望分组在白名单内 → 照常放行;
  - 期望分组在白名单外 → 自动改绑到白名单内用户可用的第一个分组(免费 key 无需任何配置即可调公益模型组),并记系统日志;
  - 期望分组为 `auto` → auto 组只能在白名单内展开(`GetRequestAutoGroups` 过滤)。
- 白名单为空 = 不限制(兼容既有行为)。

### 2. 模型隔离:独立付费分组
- 白名单外的分组即「付费分组」:只有付费余额可消耗(hc17 结算逻辑),且免费级 key 不可路由(本次新增)。
- 运营操作:在分组倍率里建好付费分组并给渠道绑定,免费分组白名单不填它即可。

### 3. 余额隔离:分开展示 + 分开结算
- 钱包页统计卡拆分:**付费余额 = 总余额 − 免费余额**;**免费余额 = 用户级赠送(签到)+ 号池每日赠送剩余**;
- 消费明细(`日志 → 内容`)新增**资金来源标注**:
  - 付费分组:`资金来源: 付费余额`;
  - 免费分组:`资金来源: 免费余额优先,不足部分扣付费余额`;
  - 订阅计费:`资金来源: 订阅额度`;
- 号池管理面板的「免费额度可用分组」说明文案更新(说明付费分组与免费 key 路由规则)。

## 升级步骤

```bash
docker load < new-api-v1.0.0-rc.43-hc20.tar.gz
docker compose -f deploy/docker-compose.prod.yml up -d
```

- 无数据库迁移(免费级 key 由 `tokens.source_channel_id` 推导)。
- 若尚未配置 `FreeQuotaAllowedGroups`(号池管理面板),白名单为空时本次隔离不生效——**需在号池管理面板把免费分组(如号池、公益模型组的分组 key)填入白名单**。

## 注意事项
- 免费级 key 调用白名单外分组的模型时会被改绑到免费分组;若该模型不在免费分组内,将报「无可用渠道」,属预期行为。
- 已知环境性存量失败(与本次改动无关):`controller` 包 `TestAuditDatabaseMatrix`/`TestAdminUserRiskOperations*`(Windows TempDir)、`service` 包 channel affinity 2 例。
